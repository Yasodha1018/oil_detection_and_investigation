# MARITRACE – AI-Powered Marine Oil Spill Detection & Vessel Attribution

**Detect. Trace. Attribute.**

MARITRACE is an end‑to‑end platform that uses satellite SAR imagery, AI segmentation, ocean drift modelling, and AIS vessel tracking to detect oil spills, reconstruct their origin, and rank potentially associated vessels with explainable evidence.

## Features

- **Satellite Analysis**: Upload SAR images or search live Copernicus scenes; run U‑Net segmentation to detect oil slicks.
- **Drift Modelling**: Forward/backward Lagrangian drift using ocean currents and wind.
- **Vessel Intelligence**: Load AIS data, filter candidates by spatio‑temporal proximity, compute multi‑criteria association scores.
- **Investigation Dashboard**: Interactive map, timeline, evidence breakdown, and report generation.
